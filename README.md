# Juice Shop Login Form

## Description

This project is a simple login form created with HTML and JavaScript that is based on the OWASP Juice Shop login page. The purpose of the project is to practice basic input validation and explore common web security vulnerabilities.

The form contains an email field, password field, login button, and an area for displaying validation messages and responses.

## Features

- Email and password input fields
- Prevents empty form submissions
- Checks that the email contains an `@` symbol
- Requires passwords to be at least 8 characters long
- Displays validation errors to the user
- Displays a welcome message after valid input is submitted

## How to Run

1. Download or clone this repository
2. Open the project folder
3. Open the HTML file in a web browser
4. Enter an email address and password into the login form
5. Click the **Login** button to test the validation

No additional software or installation is required to run the current version of the project.

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

This project was created as part of an assignment involving OWASP Juice Shop and web application security. The form will also be tested for vulnerabilities such as Cross-Site Scripting (XSS) to better understand how insecure input handling can affect a web application.
